# App layer (D25, package 23)

The future Qt UI talks ONLY to `wp.app.session.Session`. It never imports wp.core / wp.model / wp.commands directly.

- `Session(characters_dir, user_dir, clock)`: app settings, themes, catalogs, the open character.
- Reading: `session.view(panel id, **params)`. One view per panel of the registry (`wp/app/views.py`, `VIEWS`);
  the field lists are in `ARCH/view_contract.md` (generated by `tools/make_view_contract.py`, a test keeps it current).
- Changing: `session.dispatch(command, **params)` -> `DispatchResult(ok, topics, info, reason, params)`. A refusal is
  a result (reason id + params for the locale text), never an exception. `topics` = the panel ids to refresh, from
  `wp/app/data/topics.json` ("all" = every panel; a command missing from the table refreshes every panel).
  Subscribers (`session.subscribe(fn)`) get the topics after every successful command.
- Files (`wp/app/files.py`): new / open / save / close, duplicate / rename / delete (to `<folder>/trash/`, never a hard
  delete) / export / import. Before every save the old file is copied to the backups folder; only `backups_count`
  newest are kept. A damaged file is the refusal `file_corrupt` (params: path, newest valid backup);
  `restore_backup(name)` opens that backup.
- Autosave: app settings `autosave`, `autosave_mode` (interval | every_command), `autosave_interval_s`. In interval
  mode the UI timer calls `maybe_autosave()`; the clock is injected (tests use a fake clock).
- Read cache (`wp/model/cache.py`): hot read functions are memoised by (function, arguments by identity, rule scope).
  The cache lives OUTSIDE the data (never in Character), every command clears it, `cache.disabled()` turns it off.
- Performance budgets: `wp/app/data/perf_budgets.json`, checked by `tests/perf/test_perf.py` on the heavy character
  (`tests/perf/heavy.py`); `tools/bench.py [--profile]` prints the timings.
- AC zones (`RULES/ac_zones.md` draft as data): `wp/rules_data/ac_zones.json`, `wp/core/ac_zones.py`,
  `wp/model/ac_zones_view.py`; the defense view carries the 8 cells.
