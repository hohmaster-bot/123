# WIPEFINDER — с чего начать (для владельца)

Папка `Wp_claude/` — новая документация. Старые файлы в корне (`TECH`, `CONTRACT`, `PROMPT`, `LOG`, `PROJECT_MAP`, `SCHEMA`, `GLOSSARY`, `TASK_CHIPS`, `Наш план`, `AUDIT`) — только для справки, потом уйдут в архив.

## Цель v1.0
Та же механика, но:
- ядро разрезано на небольшие модули по темам;
- интерфейс на Qt (PySide6);
- два режима, включён всегда только один: **Классик** (лист во весь экран, Alt-Tab / хоткей) и **Оверлей** (лёгкая версия, нужное всегда на экране). У каждого свои настройки и свой режим редактора;
- языки: русский и английский;
- одно надёжное сохранение, без миграций старых файлов.

## Что уже готово
- Ветка `Rework`, новая документация, `.gitignore`.
- Твои правила записаны в `RULES/`, пожелания к интерфейсу — в `UI_WISHES.md`.
- Тесты по числам из правил: `tests/test_rules_baseline.py`. Что старый код считает не так — в `tests/BASELINE_REPORT.md`.
- Старая проверка `_check.py` разобрана: на сломанной формуле падает, мёртвая только проверка схемы.

## Где что
- `ARCH/decisions.md` — решения (что и почему).
- `ARCH/surfaces.md` — как устроены режимы Классик и Оверлей.
- `RULES/` — правила игры (истина). `UI_WISHES.md` — пожелания к интерфейсу.
- `OPEN_QUESTIONS.md` — что ещё решить.
- `ROADMAP.md` — этапы и текущий шаг.
- `GOTCHAS.md` — «не делай X, ломает Y».
- `tests/BASELINE_REPORT.md` — где код расходится с правилами.

Документы для Claude написаны по-английски: так они тратят меньше токенов. Этот файл — по-русски, для тебя.
