# WipeFinder: путеводитель для владельца

Файл для тебя, не для Claude. Claude читает `CLAUDE.md` в корне и файлы в `Wp_claude/RULES/`.

## 1. Что мы делаем
Переписываем приложение-лист персонажа (Pathfinder + ваши хоумрулы) с Tkinter на PySide6, но по-другому:
сначала правила и ядро с тестами, потом картинки. Два режима, которые не работают одновременно:
**Классика** (лист на весь экран по Alt-Tab или горячей клавише) и **Оверлей** (лёгкие панели поверх игры).
У каждого свои настройки и свой режим редактора. Язык RU/EN переключается, весь текст интерфейса лежит в файлах языка.
Старое приложение работает как раньше и остаётся эталоном до фазы 5. Его мы не чиним, а сверяем с ним новое ядро.

## 2. Три слоя (что за что отвечает)
```
Окна и панели (PySide6)    показывают и просят
   ↓ команды   ↑ «обновись»
Ядро (правила, Python)     считает и решает, ничего не рисует
   ↓           ↑
Данные                     файл персонажа, каталоги, настройки
```
Окно ничего не меняет само: говорит ядру «получить урон 10», ядро делает всё по правилам.
В файле хранится только основное (уровень, HP, предметы). Баланс, БП, боль, нагрузка считаются при показе.

## 2а. Три режима листа
**Игра** (обычное использование), **Тренировка** (трата тренировок на покупки), **Редактирование** (правки без ресурсов до жёстких пределов, как исправление ошибок). У каждой способности хранится источник и цена отдельно. Тренировки тратит только источник «тренировка». Подробности в `RULES/training.md`.

## 3. Правило размера файлов
Один файл отвечает за одно дело. Цель: до 500-800 строк на модуль ядра, не больше 400 на панель окна.
Файл больше 1000 строк режем. Это не красота: Claude читает файл целиком, и большой файл стоит много токенов
и чаще ломается при правке. Эту границу проверит автоматический тест, превышение будет падать как ошибка.
Модули подключаются друг к другу через импорт, поэтому для правки боли хватает прочитать один небольшой файл.

## 7. Что делать, когда что-то идёт не так
- Code пишет «тесты прошли», а ты не уверен: попроси показать команду запуска и вывод. Мы проверяем, что тест умеет падать.
- Файлы правил оказались в корне репозитория, а не в `Wp_claude/`: попроси Code перенести и убрать копии.
- Ты что-то не понял в моём вопросе: скажи «объясни проще», я переформулирую с примером.
- Не уверен в правиле: говори прямо, я запишу как открытый вопрос, а не угадаю.

## 9. Слова, которые встретятся
**Ветка**: отдельная линия работы (`Rework`). **Коммит**: сохранённый набор изменений с подписью.
**Пуш**: отправка коммитов на GitHub. **Тест**: маленькая проверка «вот вход, должен получиться такой результат».
**Ядро**: часть без картинок, где живут правила. **Панель**: кусок интерфейса оверлея.
