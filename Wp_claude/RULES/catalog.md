# Catalog

- Universal catalog loaded from files dropped in a folder on PC. Provides items, abilities, feats, injuries, almost any sheet part.
- Can buy items with gold (optional, convenience).
- Users create own catalogs and entries (items, abilities, class features, spells); players will share files.
- Filter/sort: weapons, armor and shields, source (tag = player name or module), magic items, spells, feats, "other".
  List not exhaustive.
- Everything a player creates may be added to a catalog (export to catalog to build).
- Buffs: any race/class/injury/spell ability can be turned into a buff to avoid creating statuses (Entangled, Haste, Rage) from scratch.
