## Часть 2: показатели листа
Новый модуль `wp/model/stats_view.py`.

| Что | Как считается | Откуда |
|---|---|---|
| Спасброски | база (вводится вручную) + мод. характеристики + бонусы (`save` на все, `save:fort` на один) + боль + мораль | ваш текст + defense.md; характеристика каждого спаса — данные (Q55), база вручную (Q61) |
| Инициатива | мод. Лов + бонусы `initiative` + боль + мораль | боль по resources.md («любой бросок кубика»); мораль — Q56 |
| CMB | БМА + Сил (с чертой «Фехтование» лучшая из Сил/Лов) + размер CMB + бонусы `cmb` + боль + мораль | combat.md; размер CMB вводится вручную (Q57); бонусы группы оружия не добавлены (Q58) |
| CMD | 10 + БМА + Сил + Лов + размер CMB + бонусы `cmd`, без боли и морали | формулы в RULES нет (Q59) |
| Размер в атаке | `size_mod` (то же число, что слой размера КД) идёт в попадание | combat.md (R9) |
| Урон за боль | Сил по хвату + боль (-1 за каждую) + расовый бонус (N за каждую боль) + бонусы | resources.md (R6) |
| Удачная атака | эффекты цели `lucky` для этого оружия (или для всех) снижают порог | combat.md (R7) |
| Диапазон крита | база оружия, «keen» удваивает базу, выбор «крит +1» и эффект черты `crit_range` расширяют на 1 | combat.md (R8) |

Числа в тестах я посчитал руками по тексту RULES:
- **Урон.** Сил -2, боль 2, +1 за боль: -2 - 2 + 2 = -2. Сил +2, боль 3: 2 - 3 + 3 = 2. Без расы: -1.
- **Удачная атака.** Зачарование +2 даёт 18, с выбором мастерства 17, с чертой +1 для этого оружия 16. Черта для
  другого оружия ничего не меняет. 4 выбора мастерства (вписаны принудительно), зачарование 2 и черта 1:
  20 - 3 - 2 - 1 = 14.
- **Крит.** Кинжал 19+ даёт 19, с «крит +1» 18, с «keen» 17, с чертой +1 18.
- **Спасброски.** База 3/1/2 при Тел 14, Лов 12, Мдр 8 даёт 5/2/1.
- **CMB и CMD.** CMB 9 (с болью 1 будет 8), CMD 20.

**Расхождение с заданием (Q60).** В задании сказано «предел 3 со всех источников». В RULES и в коде предел 3
стоит только на выборы мастерства, а зачарование и черты добавляются сверху. Я оставил как в RULES.
