## C. Формулы
- Безопасный разбор формул в `wp/core/formula.py`, без `eval` и `exec`.
  - Переменные: level / lvl, str_mod … cha_mod, bab.
  - Действия: + − * /, скобки; функции min, max, floor.
- **Правило округления:**
  - деление «/» — целочисленное вниз: 7/2 = 3, −7/2 = −4;
  - итог всей формулы тоже округляется вниз: level*0.5 на 3-м уровне = 1, −level*0.5 = −2.
- Формулой может быть значение эффекта и максимум пула.
- Формула проверяется при добавлении и изменении: статусы, приёмы, пулы, каталог черт. Сломанная формула, внесённая
  вручную, в расчётах даёт 0 и ничего не роняет.
- Пример ярости: Тел мод 3, уровень 4 → 13.
- **Как ограничивается текущее значение:** оно читается не выше нового максимума, а хранимое число не
  переписывается. Если Тел упал и максимум стал 11, текущее читается как 11, хранится 13.

## D. Эффекты травм

Удаление травмы убирает эффект.

## F. Блоки действий и восстановления, восстановление эффектом
- **`block_action`** (attack / move / spell_cast / heal / any) — вид показывает, что заблокировано и кем.
  **Подключённые команды:**
  - `cast_spell` отказывает при spell_cast;
  - `restore` с ресурсом hp отказывает при heal.

  Для атаки и движения команд нет, есть только флаг.
- **`block_restore`** (hp / mana / spirit / balance / pool:id / any):
  - тики, отдых, восстановление пулов в начале боя и восстановление эффектом эти ресурсы не повышают;
  - команды `restore` и `restore_pool` отказывают с причиной.

  `block_balance_regen` работает как прежде — это частный случай для баланса.
- **Восстановление эффектом:** `per_tick_restore` у статуса (mana, spirit, balance, pool:id) и разовая часть при
  запуске (мана, дух, баланс, HP, пул). Блоки учитываются.

## H. Журнал
- Каждая команда, которая что-то меняет, сама пишет запись через `dispatch`. В записи:
  - порядковый номер, вид, id команды;
  - параметры и результат — только id и числа, без текста;
  - номер раунда боя.
- Команды, которые ничего не изменили, в журнал не попадают.
- Предела по умолчанию нет; можно задать `log_limit`. Отката нет.
- Старые текстовые записи при загрузке сохраняют только id команды.
