## Проверка `_check.py`

1. `python _check.py` на нетронутом коде: **ALL OK (39 проверок), код выхода 0**.
   Одна проверка пропущена молча: `[SKIP] schema not found: E:\WpClaude\Старт\character.schema.json`.
2. Специально сломал формулу в `Character.take_damage`: баланс стал терять весь урон, а не остаток после временных HP
   (`min(remaining, ...)` -> `min(amount, ...)`).
3. Повторный запуск: **`check_take_damage` упала, «ПРОВАЛЕНО: 1 из 39», код выхода 1.** Проверка ловит поломку.
   Мой тест `RES-temphp` тоже упал (баланс -7 вместо -4).
4. `git checkout -- character.py`: файл восстановлен, `git diff` пустой.

Вывод: запись в GOTCHAS («всегда ALL OK») верна лишь частично. `main()` ловит `AssertionError` и считает провалы,
так что проверки на `assert` падают (проверено на одной, `check_take_damage`).
Не работает только `check_schema_v18`: путь к схеме указывает на несуществующую папку `Старт/` (она пропускается),
а при ошибке функция печатает `[FAIL]` и возвращает False, что `main()` игнорирует. Эту строку GOTCHAS стоит уточнить.
