## 2. Проверенные пункты, где расхождений не нашёл

Каждый пункт сверен с текстом правил. В скобках указано, чем это подтверждено: тест (T), зонд (P) или чтение кода (К).

- **Тик**: порядок «длительности -> баланс -> ДоТ» (T order-balance-then-dot, мутация «ДоТ раньше» тест ловит). Кровотечение на 3 раунда бьёт ровно 3 раза (T). Перегрузка -1 за тик, при 0 исчезает (T). Перегрузка > 0 блокирует реген (T).
- **Перегрузка**: маг X, не-маг 2X, кантрип 2X для всех, заклинание из предмета 0, ручное значение, новые касты складываются (T). Сброс при длинном отдыхе и в конце боя (T).
- **Баланс**: кап БП = ceil(maxHP/4) по МАКСИМАЛЬНОМУ HP: 11->3, 15->4, 19->5, 20->5, 21->6 (T). Максимум баланса = броня + ТЕКУЩИЙ БП + бонусы, парирование баланса не даёт (T в ядре; в модели тест слабый, M5). Реген = уровень + мод Тел + прочее, минимум 1 (T). Баланс не уходит ниже 0, переполнение идёт в ОТ, +1 боль за попадание с переполнением, в том числе при балансе 0 (T, пример владельца 10/1/1 -> -12, ОТ 11, боль 3). Поглощённое временными HP и аналогами по балансу не бьёт (T).
- **Боль**: список записей, сумма + floor(-hp/3) (T: 0, -2, -5, -7, -12, лечение -7 на 2). Смерть при сумме >= капа 8, кап меняется (12) (T). Штраф -1 ко всем броскам, кроме удачной атаки (T). Кубик крита тоже исключён (P18; это совпадает с combat.md:16). «Без штрафа», «игнорирует боль», «урон за боль» (T). Постоянная боль отдыхом не снимается (T).
- **Конвейер урона**: проценты -> плоское по типу -> временные HP -> аналоги -> HP, округление вверх (T: 10 при 25% = 8, огненный пример -3). ДР не действует на огонь (T). Части одного удара режутся каждая своим типом (P19: 8 физ + 3 огня, ДР 2, огонь 5 -> 6; тест на это слабый, M1).
- **Бонусы одного типа**: больший по модулю побеждает, равные дают 0 (+3/-4 -> -4, +3/-1 -> +3, +2/-2 -> 0) (T). Плоские, уклонение и мастерство складываются (T). Пять типов только для КД (T). Расчёт отдельно для каждой цели, примеры с моралью и героизмом (T). Зачарование +1 и +1 = +1 (T).
- **КД**: спереди, фланг, врасплох (без Ловкости и уклонения, щит только со стороны щита), парирование = max(броня, парирование), касание, щит можно выключить, перегруз ограничивает Ловкость+уклонение до +2, max Dex (T).
- **Мораль**: trunc(scale/2): 3->1, -4->-2, 1->0, -3->-1, ±10->±5 (T). Только в бою (T). Сброс шкалы в конце боя (T). На КД, удачу и крит не идёт (T).
- **Оружие**: названия уровней, цена (30+5X)*сложность*масштаб, X считает только ДРУГИЕ узлы 8+ любого масштаба (T, пример владельца «три эксперта»). Базовые навыки 50/100/150, +(5-сложность), не складываются, берётся максимум по предкам, у разновидности несколько групп (T). Квалификация -2/-4 (T). Слоты и лимиты повторов выборов (T). Прочность +30/+70 %, HP предмета +1 (T). Крит: keen удваивает базу, выборы добавляются после (T). Удача: 20 - мастерство - зачарование - прочее (T).
- **Атака и урон** (attack_view): BAB + мод хар-ки + боль + квалификация + типовые бонусы (T). Бонусы одного оружия не перетекают на другое (T). Бонусы группы идут только оружию этой группы (T). Хваты 1x / 0.5x / 1.5x, плюс округляется вниз, минус не умножается (T: +3 -> 4/1/3, -2 -> -2, +1 -> 1/0, +5 -> 7). Бонусы зачарования берутся только у надетого оружия в руках (К, `_item_bonuses`).
- **Навыки**: каталог из 45 шаблонов читается из skills_list.md (STR 1, DEX 7, CON 1, INT 22, WIS 6, CHA 8) (T). Старт: только Восприятие и Поиск, 0 рангов (T). Подвиды семейств, у каждого свои ранги (T). Цены: обычный 20*ранг, продвинутый 15*ранг, специализированный 10*ранг только выше уровня, а до уровня бесплатно (T). Продвижение 40+20*другие, специализация 200+50*другие, бесплатные тоже считаются (T). +3 у продвинутых (T).
- **Тренировки**: Хар-ка 150*max(1, новый мод) по базе+раса (T, пример 15->18 = 1500). Языки (T, все примеры владельца). Щит 100, броня 250 за ступень (T). Старт 1000, уровень 100*новый уровень (T). Комфорт: максимум 5+5*ур, курс 5+5*ур (T). Тратит только источник «training» (T).
- **Дух** = max(0, 5+5*мод Хар) + бонусы: +2 -> 15, -1 -> 0, -2 -> 0, +2 и +3 -> 18 (T).
- **Цикл**: Внимание = 1 + уровень//3 + приводы 4+ (пример 7 уровня -> 5), капа нет, `end_cycle` ничего больше не трогает (T). ОВ не моделируются (см. п. 33).
- **Постоянный урон характеристики**: в ядре верно (T). В модели ошибка, см. п. 1.
- **Короткий отдых**: +1 БП или +1 временный БП, лечение 2+ур (или больше, если даёт раса), повтор лечения за 1 БП, таблица цен, мана в первый раз бесплатно, показываются только доступные опции, излишек БП сгорает (T, пример 3 уровня 1/20). «Дневные» предметы выключаются (T).
- **Длинный отдых**: HP, БП, мана, ячейки, ресурсы классов, дух, хар-ки (кроме постоянного урона), заряды способностей, предметы с флажком, временная боль снимаются; ОТ, комфорт, заряды травм, постоянная боль, временные HP остаются; перегрузка 0, баланс до максимума, все предметы выключаются (T). Исключение — заряды статусов, см. п. 2.
- **Активации**: поле «до конца короткого/длинного отдыха», по умолчанию 1 -> день, 5 -> декада, другая цена без поля = отказ, не хватает духа = отказ (T). Предмет без цены: см. п. 6.
- **Каст при нехватке баланса**: баланс 0, +1 боль, ОТ = недостача, КС = 10+2*ОТ (T: 2/5 -> ОТ 3, КС 16).
- **Хранилище**: сохранение и загрузка без потерь, только базовые значения, атомарная запись, .bak, незнакомая версия = понятная ошибка, лишнее поле = ошибка (T).
