## 5. Где код молча принял решение, которого нет в правилах

Решения уже записаны в `CORE_REPORT.md` и `MODEL_REPORT.md`; здесь самые заметные:

1. HP макс = сумма бросков + мод Тел * уровень + бонус (`derived_view.py` `hp_max`).
2. Процент снижения задаётся только по типу урона; при нескольких частях округление вверх у каждой части отдельно (`damage.py:116-128`).
3. Кап БП при макс. HP <= 0 равен 0 (`derived.py` `bp_cap`).
4. «Игнорирует боль» снимает и штраф, и смерть; «боль не даёт штрафов» — только штраф (`pain.py:42-52`).
5. Порог крита и счастливой атаки не ниже 2 (`weapons.py:209, 216`).
6. Округление итоговой прочности вниз (`weapons.py` `final_durability`).
7. 4-я атака с тегом и дальше: -15, -20 (`combat.py`).
8. «Умирает»: всего 3 слота действий (`statuses.py:18`).
9. Спец. навык сохраняет +3 продвинутого (`skills.py:49`); «другие продвинутые» в цене считают и спец. навыки (`skills.py:75`).
10. Активация за X духа без поля «действует до» — отказ, а не значение по умолчанию (`gear_cmds.py:16-25`).
11. Конец боя снимает ВСЕ временные HP (`gear_cmds.py` `end_combat`), даже от статуса с длительностью.
12. Размер прибавляется к КД (`ac.py:76`, расхождение 13).
13. На коротком отдыхе сначала тратится временный БП (`rest.py` `_pay`).
14. Бонус к оружию действует на атаку и урон этим оружием, кроме бонуса владения (только атака) (`bonuses.py:76-80`).
15. Каталог навыков читается прямо из `Wp_claude/RULES/skills_list.md` (`skills_catalog.py` `DEFAULT_PATH`).
