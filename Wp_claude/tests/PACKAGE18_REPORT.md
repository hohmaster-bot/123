# Отчёт по пакету 18 (каталоги)

Дата: 2026-11-23. Ветка `Rework`, `main` не тронут.

## Сделано
| Что | Где |
|---|---|
| Каждый каталог — один JSON-файл: `{"kind", "format": 1, "title", "counter", "retired", "meta", "entries"}`. У записи id (делает программа из имени, транслит + номер при совпадении; удалённый id не выдаётся снова), name, sample. Неизвестные поля записи сохраняются, неизвестные поля верхнего уровня отбрасываются | `wp/catalog/store.py` |
| Два слоя: поставляемые файлы (только чтение, `wp/catalog/data/`) и пользовательские (`catalogs/<kind>.json` рядом с персонажами). Запись пользователя с тем же id заменяет поставляемую; удаление поставляемой = «надгробие»; сброс возвращает исходную | `store.merged` |
| Команды каталога (единственный путь изменений): add, edit, rename, remove, duplicate, reset, import, create. Проверка полей по таблице в данных, отказы с кодом причины. Сохранение атомарное. Вид для интерфейса: список с фильтром и сортировкой, запись со слоем | `catalog_cmds.py`, `schema.py`, `catalog_schemas.json`, `catalog_view.py` |
| Код одной записи для буфера обмена (`WFC1:...`, только ASCII) и обратный импорт; весь файл каталога экспортируется и импортируется как есть | `store.export_entry`, `catalog_import_entry` |
| Файлы по видам: weapons, weapon_groups, armor_shields (два набора, числа сохранены: 8 и 15 строк), items, spells, statuses, skills, feats, damage_types, doll_slots | `wp/catalog/data/*.json` |
| Образцы (sample = true): оружие (кроме безоружного боя), доспехи и щиты, 3 предмета, 2 заклинания, 3 статуса (ярость, аура ки, проклятая тьма), стойка «Me Liquescit» в каталоге черт | данные |
| Старые загрузчики (оружие, группы, доспехи, черты, навыки, типы урона, слоты куклы) читают через новый слой; старые файлы удалены | `weapons_catalog.py`, `armor_catalog.py`, `feats_catalog.py`, `skills_catalog.py`, `defense_view.py`, `doll.py` |
| «Медицина» теперь навык Инт: Инт 23, Мдр 5, всего 45; skills.json собран из skills_list.md, тест проверяет совпадение | RULES/skills_list.md, `tools/build_catalogs.py` |
| Перевод записи каталога в запись листа: предмет, статус | `convert.py` |
