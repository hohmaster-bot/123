# Возможности старой программы (tkinter) и новая модель — пакет 13, часть G

Источник: файлы `*.py` в корне репозитория (старая программа) и старые документы (`SCHEMA.md`, `GLOSSARY.md`).
Ничего старого не удалено. Колонка «Решение» (пакет 14 I, по ответу владельца): «ядро (пакет 14, сделано)», «ядро (пакет 15)», «ядро (пакет 16)», «UI позже» (все чисто экранные пункты), «не решено» (владелец ещё не отметил).

Колонка «В новой модели»: **да** — есть; **частично** — есть похожее, не всё; **нет** — нет.
Интерфейс (окна, кнопки, оформление) в новой модели вообще не построен (фаза 5), поэтому все чисто экранные
пункты помечены «нет (UI)».
