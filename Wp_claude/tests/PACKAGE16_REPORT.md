## Изменения старых правил (по решениям владельца в тексте пакета)
- Пул выше максимума больше не обрезается при чтении (тест `c-clamp`: ожидание 11 -> 13).
- Неизвестное поле в файле больше не ошибка, а отбрасывается (`unknown-field`, `q49-old-file`).
- Длинный отдых больше не пополняет заряды статуса без источника: три старых теста теперь связывают статус с чертой, которая восстанавливается на длинном отдыхе (ожидания те же).
- Два теста журнала считали команды без изменений; теперь входные данные меняют состояние (ожидания те же).
- Макс. HP считается по каждой кости (минимум 1 на кость); старые тесты не изменились.
- Стремления (drives) теперь записи с именем; старый формат при загрузке отбрасывается (Q124).
- Константы, перенесённые в данные: шаг итерации (`rules_settings.iterative_step`), типы урона, слоты куклы, список целей. Новые константы `SPELL_MIN_PRICE`, `BASE_POINT_TENTHS_*` пока в `core/training.py`; остальные константы из обзора 4 (около 150) тоже ещё в коде.
