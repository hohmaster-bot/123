## A. Чистка и ответы владельца

  - Активация тратит только заряд.
  - Старые файлы с ценой читаются, цена отбрасывается.
- **Q72. Замедление доспехом.**
  - Надетый доспех (на кукле, HP больше 0 — те же предметы, что дают бонус брони) вычитает свой
    `speed_penalty_ft` из скорости.
  - Новая цель эффекта `armor_slowdown_reduction`: положительное число уменьшает замедление, но не ниже 0;
    значение `"all"` убирает его совсем.
  - −10 футов за перегруз складывается с замедлением.
  - Тесты: надет 15 / в сумке 20; сломан 15 / HP 0 — 20; снижение 3 → 18, 10 → 20; «all» → 20; с перегрузом 5.
- **Q70. Стабильный id у травм.**
  - Id создаёт программа из названия, при совпадении добавляет номер.
  - Старые файлы: травма без id получает его при загрузке.
  - Контейнер показывает травму по её id.
  - Команды для травм — в пакете 13.
- **Q74. Стойки.**
  - Стойка — черта с флагом `is_stance`. У персонажа поле `active_stance`.
  - Команда `set_active_stance` отказывает, если черты нет или это не стойка.
  - Эффекты стойки действуют, только пока она активна. Обычные черты действуют всегда.
  - `end_combat` стойку не меняет. Удаление черты очищает `active_stance`. В контейнере статусов стоек нет.
  - Вид `stance_view` показывает список стоек и активную.
- **«Me Liquescit»: что нельзя выразить эффектами.**
  - «Нет бонуса уклонения к КД»: в системе эффектов нет эффекта, который отключает тип бонуса. Отрицательный
    бонус того же типа не годится: бонусы уклонения складываются, а отключение должно убирать любую величину.
  - «Нельзя зайти с фланга»: это вообще не эффект; фланг — режим КД, который выбирает игрок.
  - То же касается spells.md («стойка может отключить бонус Ловкости к КД»). Новую механику не строил (Q82).

## B. Приёмы по тегам
- **Старые приёмы-записи у предмета** (вид «maneuver», `base_record`) убраны. Все записи атаки предмета снова
  обычные. Из старых файлов такие записи выбрасываются при загрузке. Тесты пакета 9 переписаны: две записи одного
  предмета разрешены, у каждой своя группа и характеристика.
- **Список приёмов персонажа** (`Character.maneuvers`), поля:
  - id создаётся сам;
  - имя, описание;
  - `required_tags`, `tag_mode` (any/all);
  - `to_hit`, `damage`;
  - `effects`;
  - цены `cost_actions` / `cost_balance` / `cost_spirit` — **только запись**, ничего не списывается;
  - `required_feat`;
  - `condition_tag`, `favorite`, `source`, `notes`;
  - `extra` — словарь неизвестных ключей, сохраняется и не читается.
- **Команды:** `add_maneuver`, `edit_maneuver` (неизвестное поле — отказ, будущие ключи кладутся в `extra`),
  `remove_maneuver`.
- **Теги оружия** = все группы оружия + id его вида (`Item.wkind`; новое поле, его заполняет `make_item` из
  каталога).
- **`maneuver_view`:**
  - на каждое подходящее оружие в руках — отдельная строка с попаданием, уроном и CMB его основной записи плюс
    модификаторы приёма;
  - причины недоступности даются как id;
  - `granted_by` — черты, которые дают приём;
  - если оружие убрано, приём остаётся в списке, но недоступен.
- **Не делал** (так и сказано): автоматическую трату, ограничения стоек, свои счётчики («Искра»), состояния целей,
  триггеры начала раунда, изменение свойств оружия стилем. В combat.md записано, что может дать стиль и что это
  намеренно не моделируется.

## Расхождения с прежними RULES
1. **Виды записей атаки** («main» и «maneuver», пакет 9, Q38 и Q45) отменены по заданию. Записи, ссылавшиеся на
   основную, больше не наследуют её группу и характеристику.
2. **Какая запись задаёт HP и прочность предмета.** Раньше — «основная запись». Теперь у предмета все записи
   основные, поэтому берётся основная (primary) запись, а если её нет — первая (Q76). Из-за этого тест пакета 9
   `f-main-picks-only` теперь ждёт 11, а не 10.
3. **Классовая стойка.** В combat.md сказано «одна стойка + одна классовая стойка». Сейчас есть только одно поле
   `active_stance` (Q81).
4. **spells.md: «стойка может отключить бонус Ловкости к КД».** Это невыразимо (Q82).
5. **Q69.** Цена статуса из пакета 11 убрана целиком: поле, отказ и тесты `a-refuse-cost` / `a-cost-paid`. Вместо
   них тест «активация ничего не тратит».
