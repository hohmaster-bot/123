## Где правила молчали (проверь)

1. **HP макс** = сумма бросков кости + мод Телосложения за уровень + бонус, не меньше 1 (как в Pathfinder).
   В RULES только «кость бросается вне приложения, результат вписывается».
2. **Бонусы характеристик по источникам** (предметы, квирки) — простые числа, без типов бонусов.
3. **Максимум маны** вводится руками. ~~Дух и внимание~~ — владелец дал формулы (часть 2).
4. ~~Длинный отдых: баланс на максимум, перегрузка 0~~ — подтверждено владельцем (часть 2). Комфорт и внимание
   длинный отдых не восстанавливает.
5. **Боль от переполнения и от каста** записывается отдельной записью на каждый удар, источник — текст на английском.
6. **Стабильные id**: предметы `iid`, статусы `sid`; у оружия id = `Weapon.name`; у навыков пока id = `name`
   (в ядре у навыка нет отдельного id) — поправить в следующем куске.
7. **Поглотители урона**: только мана или классовый ресурс по имени.
8. **Броня, щит, натуральная броня** = наибольшее значение среди надетых предметов; макс. Ловкость = наименьшая.
9. **Журнал действий** без ограничения длины; тексты на английском (переводы через i18n позже).
10. **Короткий отдых** — одна команда со всеми тратами сразу (как окно с кнопкой «Применить»).
11. **Бонус к оружию** теперь действует на атаку и урон этим оружием (нужно для примера с натуральным оружием).
12. **Старый baseline** `MAG-*` проверяет старое правило перегрузки (длительность). Я его не менял: это снимок старых
    правил против старого кода. Эти 4 строки в BASELINE_REPORT теперь устарели.

# Расчёт атаки и урона (`wp/model/attack_view.py`)

## Что сделано

- **Модель**: у листа появился ББА (`bab`, базовое значение, вводится руками) и черты (`feats`: id, название, флаги,
  источник, цена). У предмета-оружия — хват (`grip`: одна рука / вторая рука / две руки), признак фехтовального
  оружия (`finesse`) и принудительная характеристика атаки (`attack_stat`, для квирков и рас).
- **Каталог черт как данные**: `wp/catalog/data/feats_default.json` (первая черта «Фехтование», `finesse_training`,
  цена 200, флаг `finesse`), загрузка `wp/catalog/feats_catalog.py`. Команда `add_feat` (цена шаблона,
  тратит тренировки только при источнике «тренировка»; дважды взять нельзя).
- **`attack_view.attack(ch, item, stat=None, crit_mult=2)`** даёт разбивку по строкам с источниками:
  - к попаданию: ББА; модификатор характеристики; штраф квалификации (-2 / -4); штраф боли (-1 за боль);
    затем по одной строке на тип бонуса, уже сложенные по правилу «больший по модулю побеждает»: бонусы
    оружейной группы, бонус владения (бонус мастерства «атака +1» как proficiency), мораль от шкалы,
    бонусы предметов и статусов;

## Где правила молчали (допущения, проверь)

1. **ББА** в правилах есть только как «BAB progression» в редакторе класса (`classes_magic.md`), формулы нет.
   Хранится числом, вводится руками.
2. **Фехтование**: по `combat.md` «тогда берётся лучшая из Силы / Ловкости» — так и сделано; без черты всегда Сила.
   На урон фехтование не влияет: урон всегда от Силы по хвату (как велел владелец).
3. **Бонус мастерства «атака +1»** берётся только с узла самого оружия (не с его групп). Бонусы мастерства групп
   (если их выбирать на узле группы) к оружию этой группы не переходят.
4. **Свойства предмета-оружия** (вкладка эффектов) к атаке и урону действуют только на атаки этим оружием;
   бонусы на атаку от другого надетого оружия к этой атаке не идут. Бонусы предметов не-оружия (кольца, пояса)
   идут на все атаки.
5. **Безоружная атака** использует узел оружия с id `unarmed`, если он есть в каталоге (уровень, мастерство,
   квалификация); хват — одна рука.
6. **Боль** — отдельная строка (флэт -1 за боль), а не типизированный бонус; на урон тоже действует.
7. **Итеративный штраф** (-5 / -10) в эту разбивку не входит: он зависит от порядка опций в ходу (`wp/core/combat.py`).
8. **Счастливая атака и порог крита** здесь не считаются (функции есть в `wp/core/weapons.py`), только текстовая подсказка крита.
9. **Размер** к атаке не прибавляется: в модели есть только `size_mod` для КД; правила говорят «размер влияет на атаку,
   CMB, CMD», но таблицы нет.
