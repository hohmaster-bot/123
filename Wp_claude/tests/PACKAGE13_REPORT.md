## B. Эффекты-блоки
- **Источники:** активный статус, черта (стойка — только активная), действующая вкладка надетого или взятого в
  руку предмета. **Травма источником быть не может:** у травм в модели нет эффектов (Q89).
- Блок снимает только положительные значения. Штрафы остаются всегда.
- **`block_balance_regen`** — баланс не восстанавливается. Видны причины: `overload` и id источников.
- **`block_bonus`** (тип или `any`; область `all` или список целей) работает в сумме бонусов, спасах, навыках, КД и
  таблице атак (попадание, урон, удачная атака, крит).
  - Блок уклонения для КД **убирает и положительную часть Ловкости** — это получилось. Штраф низкой Ловкости
    остаётся: Лов 8 + уклонение 1 = КД 10, с блоком 9.
- **`block_stat_bonus`** — положительный модификатор характеристики считается за 0 везде: КД, Реакция, атака,
  урон, переносимый вес. Отрицательный остаётся.
- **`cannot_be_flanked`** — атака с фланга считается как атака спереди.
- **Стойка «Me Liquescit»** теперь выражается эффектами: Лов 14, уклонение +1, щит +2. Без стойки — спереди 15,
  с фланга 13. В стойке — 12 и 12.

## C. Пулы ресурсов и статусы с платой за раунд
- **Пул:** id, имя, максимум, текущее, правило восстановления `short_rest` / `long_rest` / `combat_start` /
  `manual`.
  - Команды `add_pool`, `edit_pool`, `remove_pool`, `spend_pool` (ниже 0 — отказ), `restore_pool`.
  - Отдых и начало боя восстанавливают пулы по их правилу.
- **У статуса новые поля** `charge_source` (`own` или id пула) и `charge_per_round`.
  - На каждом тике активный статус платит до того, как уменьшится его длительность. Нечем заплатить — статус
    заканчивается.
  - Запуск с пулом требует запас хотя бы на один раунд, но ничего не списывает.
- **Пример «Ки»:** пул 3, плата 1 за раунд. Тики 1–3 платят (2, 1, 0), на 4-м тике платить нечем, статус кончается.

## D. Расходники
- Новые поля `quantity`, `consumable`, `on_use_status`; команда `use_consumable`.
- Вес = вес одной штуки × количество.
- При количестве 0 предмет остаётся в списке, серый и без веса. Удалить можно только через `remove_item`.
- `on_use_status` запускает статус при использовании.

## E. Список активного (только данные для интерфейса)
- Разделы: атаки (только доступные), включённые предметы, заряды предметов, активные статусы с флагом «скрыт»,
  расходники.
- **Пробел:** заряды предметов хранятся по имени (`Character.charges` вида item) и не привязаны к предмету. Поэтому
  отфильтровать их по «надет / включён» нельзя; показываю все заряды вида item (Q94).
